AutonoMe is a fully autonomous AI agent for Windows and Windows Server that understands what you need and does it for you. Opening apps, writing documents, and automating your workflow with plain English commands.

Describe your task
Type a request the way you'd explain it to a coworker. "Read the sales report on my Desktop and create a summary for my manager". That's all it takes.

AI plans the action
Autono-Me finds the right files, reads their contents, selects the right applications, and builds an automation plan. All in seconds.

Your computer takes over
Applications open, documents are written, files get managed. You can watch it happen in real time; or just come back when it's done.

Requirements:
Visual Studio
Administrator Account
Ollama
Capable Vision Model
.NET 8.0
